# Divergences

Every deliberate difference between the Python engine and a service's reference. The format and rules are in [README.md](README.md). A row without an approver is a proposal: until it's signed off, the Python must match the reference.

Not listed, because they don't change a correct single request's output: the command injection (`CGI-5`) and the shared temp file (`CGI-6`) in the cSNP CGI. They are never replicated. Batch state (`SCORE-7`, `SCORE-8`) doesn't arise in the service either: it scores one protein, so one family, per call, as the CGI did. Row 3 stays a proposal for batch use. Still open, with no proposal to log: the species file (`DATA-3`). Rows 4 and 7 follow the rule for legacy code and docs that disagree: the port follows the code, and the docs' version is revisited once the service is live on production (`CLAUDE.md`, `CONTRIBUTING.md`). See the open questions in [tech-stack.md](../design/tech-stack.md#open-questions).

Quirk IDs refer to the cSNP legacy behaviour spec (`panther-workspace/legacy/cSNP_analysis/.specs/2026-10-28-legacy-behavior-spec.md`). Its §7 has the sample and edge-case inputs (`del1`–`del35`, `e1`–`e10`) these rows cite.
