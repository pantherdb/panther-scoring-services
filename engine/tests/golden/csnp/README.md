# cSNP Golden Files

The reference outputs the `csnp` port must match, byte for byte, and the inputs that produced them. How they are used, and why each input is in the set, is in [docs/parity/](../../../../docs/parity/README.md): `golden-setup.md` and `inputs.md`.

Every file here is stored byte for byte (`-text` in `.gitattributes`). Some carry a carriage return on purpose.

## Regenerating

- **`release/`** never changes: copy the files from the release again, and check their sha256 against the tables above. `HUMAN` and `sample.input` are pinned in the spec's §7.1 too.
- **`spec/`** never changes either. If the reference image's self-check doesn't reproduce it, the image is wrong, not the file.
- **`generated/`, `blast/`, and `example/`'s `.snpparse` and `.out`:** the commands are in `docs/parity/golden-setup.md`. Regenerate them when the data sample, the generator or BLAST+ changes. `example/apoe.fasta` and `apoe.input` don't change.
